Quran Errors Highlighter — Android APK wrapper

This project wraps the live GitHub Pages application:
https://abdulrhman3333.github.io/quran-errors-hilighter/

Fastest method:
1. Open this folder in Android Studio.
2. Let Gradle sync/download dependencies.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. The debug APK will be at:
   app/build/outputs/apk/debug/app-debug.apk

Alternative:
Push this project to a GitHub repository with the .github/workflows/build-apk.yml file.
GitHub Actions will build the debug APK and publish it as a downloadable workflow artifact.

The APK opens the live HTTPS app in a fullscreen WebView, so it uses the same application
and backend as the current website. Internet permission is required.
